# FoodTweaks
Simple mod that adds configurable bonus stamina and eitr regen to foods that increase your stamina or eitr. Also updates the tooltips for food to display the regen they provide and includes the total regen from food in the active status effects menu.

**Server-Side Info**: This mod does work as a client-side only mod and only needs to be installed on the server if you wish to enforce configuration settings.

## Instructions
If you are using a mod manager for Thunderstore simply install the mod from there. If you are not using a mod manager then, you need a modded instance of Valheim (BepInEx) and the Jotunn plugin installed.

## Configuration
Changes made to the configuration settings will be reflected in-game immediately (no restart required) and they will also sync to clients if the mod is on the server. The mod also has a built in file watcher so you can edit settings via an in-game configuration manager (changes applied upon closing the in-game configuration manager) or by changing values in the file via a text editor or mod manager.

- EnableExtraStaminaRegen: Whether to enable gaining extra stamina regen from food.
- ExtraStaminaRegenFromFood: The percent increase in stamina regen per 10 points of stamina gained from food.
 
- EnableExtraEitrRegen: Whether to enable gaining extra eitr regen from food.
- ExtraEitrRegenFromFood: The percent increase in eitr per 10 points of eitr gained from food.


## Known Issues
None so far, tell me if you find any.

## Compatibility
Should be compatible with most mods and is fully compatible with MyLittleUI and ImpactfulSkills. 
This mod is also compatible with StaminaExtended and EitrMagicExtended but if you are using both of those there is no reason to use this mod.

Note that this mod only provides bonus regen based on the increases to stamina and eitr that you get from food. Increases to your base stamina or eitr from other mods, 
such as those by ImpactfulSkills, will not affect the bonus regen provided.
